# Qixuan Fang — Academic Homepage

This is a Jekyll-based personal academic homepage hosted by GitHub Pages.

## Structure

- `index.html`: About page
- `research.html`: Research page
- `teaching.html`: Teaching page
- `seminars.html`: Seminars page
- `life.html`: Non-academic life page
- `contact.html`: Contact page
- `_layouts/default.html`: shared page layout
- `_includes/header.html`: shared navigation header
- `_includes/footer.html`: shared footer
- `assets/css/style.css`: site styling

## Notes

Do not add a `.nojekyll` file. This site needs Jekyll processing.

The "Last updated" line is generated using Jekyll's `site.time`.
