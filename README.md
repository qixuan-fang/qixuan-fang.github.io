# Qixuan Fang — Jekyll academic homepage

This is a safer Jekyll/GitHub Pages package. It avoids complicated YAML configuration so that GitHub Pages has fewer chances to fail while parsing `_config.yml`.

## Important

Do **not** include a `.nojekyll` file in the repository.

## How to use

1. Delete the old files in your `<username>.github.io` repository.
2. Upload all files from this folder to the repository root.
3. Go to `Settings → Pages`.
4. Use `Deploy from a branch`, branch `main`, folder `/root`.
5. Wait a few minutes.

The footer date is generated automatically by Jekyll with `site.time`.
